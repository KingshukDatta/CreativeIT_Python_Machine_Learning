# 🤖 CreativeIT — Python Machine Learning

> All the code, datasets, models, and notes created during my **Python Machine Learning** course at [Creative IT Institute](https://www.creativeitinstitute.com/).

## 📌 About This Repository

This repository is a comprehensive collection of everything built, practiced, and learned throughout the **Creative IT Python Machine Learning** course. It covers classical ML algorithms, model building, data exploration, and hands-on classwork — all implemented in **Python** using **Jupyter Notebooks**.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/KingshukDatta/CreativeIT_Python_Machine_Learning.git
cd CreativeIT_Python_Machine_Learning
```

### 2. Install dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

Then navigate to the **Classworks/** folder to start exploring the notebooks.
